# NexusFlow — AI Productivity Workspace

A premium frontend productivity suite with notes, tasks, Kanban, calendar, analytics, and a focus timer.

## Features
- Dashboard with KPIs and charts
- Notes with tags, pinning, search
- Tasks with drag‑and‑drop reorder
- Kanban board (drag between columns)
- Calendar with task indicators
- Analytics (recharts)
- Pomodoro focus timer
- Dark/light mode & accent presets
- Command palette (⌘K)
- Keyboard shortcuts
- Fully responsive

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Framer Motion
- Zustand
- Recharts, Lucide icons, react‑calendar, @hello‑pangea/dnd

## Getting Started
1. Clone repository
2. npm install
3. npm run dev
